# FraudSentinel – Sistema de Apoio à Prevenção à Fraude

## Sobre o Projeto

O FraudSentinel é um projeto acadêmico desenvolvido com o objetivo de simular uma solução voltada ao apoio de processos de prevenção à fraude em ambientes digitais. A proposta surgiu a partir da necessidade de estruturar informações, organizar fluxos de análise e representar processos relacionados à identificação de riscos e validação de dados.

O projeto foi construído considerando conceitos amplamente utilizados na área de tecnologia, segurança da informação e análise de sistemas, buscando aproximar o ambiente acadêmico de situações encontradas no mercado profissional.

## Objetivo do Projeto

Desenvolver uma solução conceitual capaz de representar processos relacionados à prevenção à fraude, permitindo a organização de informações, o mapeamento de regras de negócio e a modelagem de fluxos operacionais.

Além disso, o projeto teve como objetivo aplicar conhecimentos adquiridos durante a graduação, integrando análise de sistemas, modelagem de dados, documentação técnica e prototipação de interfaces.

## Tecnologias e Ferramentas Utilizadas

* SQL
* Modelagem de Banco de Dados
* UML (Unified Modeling Language)
* BPMN (Business Process Model and Notation)
* Draw.io
* Figma
* Documentação Técnica
* Análise de Sistemas

## Principais Atividades Desenvolvidas

* Levantamento e análise de requisitos.
* Modelagem de processos de negócio.
* Criação de diagramas UML.
* Estruturação de banco de dados.
* Desenvolvimento de fluxos operacionais.
* Prototipação de interfaces.
* Documentação das funcionalidades e regras de negócio.

## Aprendizados Obtidos

Durante o desenvolvimento do FraudSentinel, foi possível fortalecer competências relacionadas à resolução de problemas, pensamento analítico, organização de sistemas e documentação técnica.

O projeto também contribuiu para ampliar a compreensão sobre a integração entre tecnologia, segurança digital e processos de negócio, demonstrando a importância da modelagem adequada de dados e da documentação clara para o sucesso de soluções tecnológicas.

Além dos aspectos técnicos, a experiência proporcionou o desenvolvimento de habilidades de planejamento, comunicação e visão estratégica, fundamentais para profissionais que atuam na área de tecnologia.
